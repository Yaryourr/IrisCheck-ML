what does IrisCheck do?

IrisCheck is a machine learning model that is focused on diagnosing 4 different diseases based on an image of your eye which are: pinkeye, anemia, jaundice and cataract! DISCLAIMER: this project is still not 100 percent accurate and its not a fully dependable source of diagnosis, if you feel like something is wrong please go to the doctor!
