##Features 
1. Diagnosis 4 diseases by imaging the eye state, Cataract, Anemia, Pinkeye and Jaundice.
2. Low to no cost digital diagnostic tool, only requires having a device with a camera and web browser to be used
3. Easy Technical project with High Impact and can be improved by research (regarding accuracy & reliability)
